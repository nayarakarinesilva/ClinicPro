# 🏥 ClinicPro

ClinicPro é uma aplicação web para gerenciamento de clínicas e consultórios médicos, desenvolvida com **Next.js**, **React** e **Material UI**.

O sistema tem como objetivo centralizar o gerenciamento de pacientes, consultas e informações clínicas por meio de uma interface moderna, intuitiva e responsiva.

> 🚧 O projeto está em desenvolvimento.

---

## Funcionalidades

- 🔐 Autenticação de usuários
- 📊 Dashboard
- 👥 Gestão de pacientes
- 📅 Agendamento de consultas
- 📋 Prontuários eletrônicos

---

## Tecnologias

- Next.js
- React
- Material UI
- JavaScript
- Context API
- ESLint

---

## ⚙️ Como executar

Clone o projeto:

```bash
git clone https://github.com/nayarakarinesilva/ClinicPro
```

Acesse o diretório:

```bash
cd ClinicPro
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

A aplicação estará disponível em:

```bash
http://localhost:3000
```
